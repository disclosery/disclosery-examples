# Contributing

Open an issue describing the research task, then submit a small reproducible recipe.
Prefer standard-library clients and clearly synthetic fixtures. Preserve the response's
period, units, warning flags, citations and quota envelope. Handle errors explicitly.

Do not commit API keys, personal information, notebook outputs from private accounts,
bulk identifier mappings or copyrighted datasets. Clear notebook outputs before a pull
request. Explain expected call counts and any paid-plan requirement. Contributions are
provided under this repository's MIT license; submit only material you may license.

Use issues for examples and documentation questions. Service availability and API
coverage remain governed by the live documentation at https://disclosery.com/docs.
