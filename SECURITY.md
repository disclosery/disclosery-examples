# Security

Never include an API key in an issue, screenshot, URL or notebook output. Revoke an
exposed key through https://disclosery.com/account/keys and remove it from local history.

For a vulnerability in these examples, use GitHub's **Report a vulnerability** option
when available. If private reporting is unavailable, use the contact route displayed
on https://disclosery.com; do not publish exploit details or credentials in an issue.

This repository is an example client, not the service source. It does not accept
credentials, provide an account recovery channel or run a security bounty program.
